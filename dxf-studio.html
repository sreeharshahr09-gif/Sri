5 · Closed-profile check

Snap tolerance
Closed loops– Open chains– Open endpoints (red ✚ on canvas)– Selected net area– Selected perimeter–
Join & close welds touching LINE/ARC segments (within tolerance) into single polylines and marks loops as closed — gaps ≤ tolerance are healed. Bridge gap lets you click two open endpoints (red ✚) and draws a straight line between them to close the profile. Delete open-ended removes geometry that still isn't part of a closed loop. All are undoable (Ctrl+Z).
One click: deletes dimensions/text/construction/hatch/frames in the selected drawings, joins & closes chains, then deletes anything still open.

6 · Tie-bar hatch 0

Mark an enclosed region as a tie bar. It is exported as a real DXF HATCH on layer TIEBAR so tools like TLPT recognise it automatically. Including a hatch upgrades the clean export to DXF 2000 (AC1015).
Pattern
Tip: if a region is bounded by separate lines, run Join & close chains first (or draw its outline with the Polyline tool), then hatch it.

7 · Export

Format
Writes a minimal, self-consistent DXF with only the exported geometry — no leftover dictionaries, dimension-association objects or unused blocks that can make strict readers (CAM / stiffness tools) fail to load the loops. Arcs are preserved as polyline bulges.
⚠ Copies the original HEADER/TABLES/BLOCKS/OBJECTS verbatim. If you deleted dimensions or text, their association objects may be left dangling and some strict readers will reject the file. Use only if you specifically need the original blocks/metadata.
Deleted & hidden entities are never exported. In Clean mode, extents are recomputed so tools auto-zoom to the geometry. Recenter shifts all exported entities by the same offset, preserving relative layout.
